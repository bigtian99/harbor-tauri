# 动漫落地页三版模板设计

**日期**：2026-07-29  
**状态**：已定稿（三版都保留）  
**范围**：`templates/anime`、`anime-1`、`anime-2`

## 1. 目标

在落地页体系内新增「动漫」分类模板，少年漫画开战页气质，可生成 / 预览 / FTP 上传；视觉与现有 `comic` 明显区分。

## 2. 方案

保留三套平行模板（用户确认「都要」），目录命名与 `comic` / `comic-1` 一致，便于 `type_code` 前缀匹配。

## 3. 不变量

- 占位符仅 `{{NAME}}` / `{{LOGO}}` / `{{DOWNLOAD_URL}}`
- 二维码由页面 JS 生成（本地 vendor，不依赖外网 CDN）
- 不新增后端字段；不引入第三套前端框架

## 4. 三版差异（仅视觉）

| 版 | 签名元素 | 色板 |
|----|----------|------|
| A `anime` | 冲击波 +「ドン！！」 | 纸白 / 墨黑 / `#e60012` |
| B `anime-1` | 朱印 + 网纹章扉 | 深黑 / 奶油 / `#ffd400` |
| C `anime-2` | 分镜网格 + GO!! | 夜蓝 / 电青 / 品红 |
